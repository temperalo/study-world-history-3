Начало потока: **разбор** входящего. Решает, что с ним делать. **Не проектирует модуль и не исполняет** — это `/plan` и `/go`.

Поток: **`/in` → `/plan` → `/go`**.

## Вызов

```
/in <хочу выучить … | вопрос>   разобрать сейчас
/in                             пройти накопленное в docs/inbox.md
```

## Алгоритм

1. **Тип входа:** «хочу выучить» (кандидат в модуль), вопрос (узнать/решить) или разведка (проверить осуществимость темы пачкой вопросов до создания модуля).
2. **Контекст:** `docs/roadmap.md`, `docs/backlog.md`, `docs/plans/plans.md`, активный модуль.
3. **Решить исход** (очевидно — решить; иначе один вопрос с вариантами).
4. **Маршрутизировать** по таблице.
5. **Исход всегда записан (gate):** из `docs/inbox.md` — пометить строку `[x]` + исход. **Flow (gate):** строка в `docs/flow.md`: `<дата> | /in | <вход> | → <исход>`.

## Исходы

### «Хочу выучить»

| Исход | Когда | Действие |
|-------|-------|----------|
| **Новый модуль** | тема ясна, есть применимый результат, не дублирует активный | → `/plan` (построить модуль) |
| **В roadmap** | стоит, но это карта/тур, не сейчас | добавить строку в `docs/roadmap.md` (☐) → стоп |
| **В бэклог-глубины** | углубление/копнуть потом | append `docs/backlog.md` → стоп |
| **Это пред-модуль** | для X нужно сперва Y | предложить Y как модуль (frame-check) |
| **Отказ** | не учим (вне предмета/цели) | строка в session-log «отклонено: <причина>» → стоп |

### Разведка (учебный spike)

| Исход | Когда | Действие |
|-------|-------|----------|
| **Разведка пачкой** | осуществимость под вопросом: источники, пред-модуль, объём | исследовать список вопросов → finding в `docs/backlog.md` / `docs/roadmap.md` + решение «брать / отложить / заблокировано», не модуль |

### Вопрос

| Исход | Когда | Действие |
|-------|-------|----------|
| **Ответить сейчас** | разовое, не тянет на модуль | tutor/ inline ответ → без артефакта |
| **Это модуль** | вопрос на самом деле = навык для практики | предложить модуль → `/plan` |
| **В бэклог** | на потом | append `docs/backlog.md` → стоп |

## One-module rule

Один активный модуль за раз. Если активный есть и не `Done` — новый «хочу выучить» по умолчанию идёт в **roadmap/backlog**, не в новый модуль (минимум шума, breadth-нюанс). Явное «хочу переключиться» — подтвердить.

## Return format

```
📥 Разбор: <вход одной фразой>
Тип: хочу выучить | вопрос
Исход: <модуль | roadmap | бэклог | пред-модуль | отказ | ответить>

Дальше: <следующий шаг — /plan, или «стоп»>
```

## Правила
- Один вход = один исход. Вопрос ≠ всегда модуль; не плодить модули.
- Проектирование модуля (цель/теория/практика/шаги) — это `/plan`, не здесь.
