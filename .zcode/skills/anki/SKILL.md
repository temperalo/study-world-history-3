## Когда

Кусок учёбы — **атомы на recall** (термины, факты, формулы, распиновки, даты, классификации: Big Five, 6 принципов Чалдини, температуры филаментов, `f≈1.44/((R1+2R2)C)`), а не навык-через-практику. tutor/`/do` это распознаёт и зовёт `/anki`. Зубрёжку не пихать в модуль — она мешает practice-first.

## Вызов

```
/anki <модуль | тема>     сгенерить колоду
/anki                     по активному/последнему модулю
```

## Что делает

0. **Факт-гейт:** у модуля/темы есть якоря (`<артефакт>.anchors.md` / §«Реперные точки»)? Нет → **STOP**: «сначала `/fact-check`, потом `/anki`» — Anki = двигатель зубрёжки, глюк в карте = заученный глюк. Есть → карты генерируются **только** из фактов со статусом ✅ (или ⚠️ в формулировке «спорно: …»); UNVERIFIED и 💭-риторика в карты не попадают. (Правила — fact-checking.md §6.)
1. Собрать атомы из модуля/темы — пары **вопрос → ответ** (recall, не узнавание): «формула частоты 555?» → «f≈1.44/((R1+2R2)C)»; «6 принципов Чалдини?» → «…». Коротко, по одному факту на карту.
2. Записать колоду в `artifacts/anki/<slug>.tsv` — формат **`Front<TAB>Back<TAB>тег`** (по строке на карту; при импорте третья колонка мапится в Tags, тег = `Предмет::slug` — см. «Структура колод»). Существующий файл — **дописывать** (Edit), не перезатирать.
3. Отметить: строка в `docs/journal.md` («колода <slug>: N карт») + при необходимости в `docs/skill-map.md` (тема ушла на зубрёжку в Anki).

**Дедуп-гейт (обязательный шаг перед заливкой):** до `addNotes` сверить TSV сам с собой и с уже залитыми картами колоды (`notesInfo` по `deck:<Предмет>`). Ловить два вида дублей: (а) точные — повтор первого поля; (б) **смысловые** — одна суть в разных формулировках («Стена и башня Иерихона» ↔ «Иерихон», «Письмо: таблички Урука» ↔ «Урук»). Смысловой дубль схлопывать в **одну именную карту** (фронт = имя/термин, бэк = суть + уникальные детали факт-карты); если факты расходятся — не гадать, вернуть на проверку к якорям. В отчёте указать: залито N, дублей M, схлопнуто смысловых K.

## AnkiConnect (дефолт)

Сразу после записи TSV (шаг 2) залить карты через AnkiConnect `localhost:8765`: пинг (`version`) → `createDeck` «<Предмет>», если колоды нет → `addNotes` (deck «<Предмет>», поля Front/Back, tags из колонки 3). Дубликаты Anki отсекает сам (`allowDuplicate: false`) — в ответе указать: залито N, дублей M. Anki не запущен / API недоступен → **не падать**: TSV уже записан как источник, сообщить «залей руками: File → Import, колонку 3 → Tags». Порядок железный: сначала TSV, потом заливка — репо всегда источник.

**Запрет кодировки (инцидент 2026-09-28):** HTTP-запросы к AnkiConnect — **только python-скриптом** (`urllib` + `json.dumps(...).encode("utf-8")`). **curl из Git Bash НЕ использовать** — бьёт кириллицу в UTF-8, создаёт мусорные колоды вида `???????` и молча теряет теги. После заливки проверять счёт через `findCards` (`deck:<Предмет>` / `tag:<тег>`) python'ом — не curl'ом.

**Имя модели резолвить, не хардкодить:** в локализованных коллекциях `Basic` называется иначе («Простая» в русской сборке; поля могут остаться Front/Back, но бывают переведены). Перед `addNotes`: `modelNames` → выбрать базовую модель → `modelFieldNames` → мапить Front/Back на фактические имена полей. Нет python → держаться правила «TSV — источник» и отдать импорт пользователю руками.

## Правила
- Карты — **атомарные** (один факт), вопрос требует вспомнить, не выбрать.
- **Структура колод (канон 2026-09-28, ред. 2):** **одна колода на предмет** («История», «Электро», …) — без подколод на модули; лимиты (new/day, max reviews) стоят на колоде предмета. Модуль/эпоха — **иерархический тег** на карте: `Электро::m1-dc-yazyk`, `История::epoch-01` — виден деревом в браузере; крамс/пауза модуля — поиском по тегу. Микс предметов в сессии НЕ делаем (блоки по предметам); интерливинг модулей внутри предмета Anki делает сам. Повторный импорт того же TSV — дубликаты отсекает Anki по первому полю.
- **Только проверенные факты:** ✅ (или ⚠️ «спорно: …»); UNVERIFIED/💭 → не карта. Нет якорей → сначала `/fact-check` (шаг 0).
- Не дублировать карты при повторном вызове (свериться с существующим `.tsv`).
- Не выдумывать факты — только то, что в модуле/проверено. Не уверен → не карта.
- Anki = recall атомов. Понимание/применение/связи — это `/exam` (examiner), не сюда.
- **Model: haiku** — механическое преобразование готовых атомов в пары Front→Back. Если skill эволюционирует в **дизайн вариантов ответов / дистракторов** (multiple-choice, выбор что и как спросить) — это уже рассуждение, поднять до opus.
