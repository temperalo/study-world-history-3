Журнал (`docs/journal.md`) — лента пройденного. Основной автор — `/deploy`. Этот скилл для ручного.

## Вызов

```
/journal <текст>    добавить заметку вручную (вне deploy)
/journal            показать последние записи + сводку прогресса
```

## Добавить (`/journal <текст>`)

Append сверху в `docs/journal.md`: `## <дата> — <тема>` + текст. Если относится к модулю — упомянуть `moduleId` и ссылку на `artifacts/`. Коротко (3–6 строк).

## Показать (`/journal`)

- Последние 5 записей.
- Сводка: модулей `Done` (из `plans-done.md`), областей потрогано (из `roadmap.md`), последний `/exam`.
- Если давно нет записей при активном модуле — мягко напомнить про `/deploy`.

## Правила
- Не выдумывать достижения — только то, что реально в артефактах/истории.
- Не перезаписывать прошлые записи (append-only).
