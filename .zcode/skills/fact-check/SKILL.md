## Контракт

`/fact-check` гарантирует: ученик не заучит непроверенное. Проверку делает ТОЛЬКО агент `checker` (Task) — независимый от tutor. Tutor не верифицирует себя сам. Правила и красные флаги — [fact-checking.md](../../rules/guides/fact-checking.md).

## Вызов

```
/fact-check                       активный/последний контентный артефакт (пост-чек)
/fact-check <файл|модуль|выпуск>  конкретный артефакт
/fact-check --pre <модуль>        пре-чек ядра модуля (зовётся из /plan до гейта Approved)
```

**Пре-чек (`--pre`):** проверяется ядро модуля — то, что гарантированно прозвучит на первой сессии: крючок, мини-теория (§2), ключевые факты шага 1 (даты/числа/параметры/формулы), цепочки причин-следствий (по звеньям). Якоря пишутся в «Реперные точки» модуля. Без пре-чека фактологический модуль не апрувится. Пост-чек артефакта не отменяется — он ловит free recall ученика и импровизацию диалога.

## Процесс (делегировать checker через Task)

1. Read артефакта (+ существующих якорей).
2. Извлечение кандидатов по красным флагам (гайд §2).
3. Группировка в якоря-блоки; сортировка по риску.
4. Верификация top-риска (web / даташит / норматив; ≥2 источника на сильное).
5. Запись `<артефакт>.anchors.md` (для модуля — секция «Реперные точки»): блоки, статусы, ссылки, дата+вердикт.
6. Правки текста при расхождениях; UNVERIFIED — честно, с пометкой в тексте.

Task-промпт передать: путь артефакта, существующие якоря, ссылку на гайд. checker возвращает вердикт по контракту (`verified N | fixed N | unverified N` + правки + ошибки).

## Гейт deploy

`/deploy` контентного артефакта требует: якоря на рискованные факты + чекер-вердикт `verified|fixed`. Иначе — отказ с пояснением ИЛИ публикация с явной пометкой UNVERIFIED в тексте и записью в lecture-log.

## Гейт anki (в /anki)

Карты — только из фактов ✅ (или ⚠️ «спорно: …»). UNVERIFIED и 💭 в карты не попадают. Нет якорей у модуля → сначала `/fact-check`.

## Исход

- Вердикт в `docs/lecture-log.md` (выпуск/сессия): `verified N | fixed N | unverified N` + найденные ошибки (ошибки не прячутся — это метрика качества).
- Возвращённые правки применяет checker (Edit) или main — контент без вердикта наружу не уходит.
- Flow-строка: `<дата> | /fact-check | <артефакт> | → verified|fixed|unverified N`.

## Правила

- **Проверяем по риску, не всё** — большой артефакт: top-риска сначала, хвост явным списком UNVERIFIED.
- **Не блокировать мягкие курсы** — техники/упражнения якорятся «методика-источник», без бюрократии (гайд §8).
- **Unsafe-темы** (электробезопасность, LiPo, химия, медицина) — только «подтверждено нормативом» или UNVERIFIED; UNVERIFIED к публикации запрещён.
- **model: opus** — оркестрация и сведение вердикта; сама верификация идёт в checker (GLM-5.3, frontmatter агента).
