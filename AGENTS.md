# world-history — учебный курс

Рабочий протокол — **[CLAUDE.md](CLAUDE.md)** в корне: читай его первым и следуй как единственному источнику истины (одинаково для Claude Code и ZCode). Этот файл — тонкий указатель, не копия.

Папка автономна: внешних зависимостей нет — ни удалённых репозиториев, ни sync-скриптов, ни MCP/токенов. Всё нужное внутри: правила в `.claude/rules/`, скиллы в `.claude/skills` (зеркало для ZCode — `.zcode/skills`), субагенты `tutor` / `examiner` / `checker` в `.claude/agents` (и `.zcode/agents`).
