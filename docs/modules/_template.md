Одна фраза — что я **смогу делать** после модуля (не «узнаю про», а «смогу собрать / написать / применить X»).

## Реперные точки (якоря фактов) — для фактологических модулей

> Рискованные факты модуля (даты, числа, «первый/самый», формулы, номиналы, безопасность, **цепочки причин-следствий**) — якорями (формат `docs/anchors/_template.md`, правила — `.claude/rules/guides/fact-checking.md`). **Пре-чек — при `/plan`** (`/fact-check --pre`): проверяется ядро, которое прозвучит на первой сессии (крючок, §2, ключевые факты шага 1, причинные цепочки) — до гейта Approved. **Пост-чек — артефакт перед `/deploy`** (ловит free recall ученика и импровизацию диалога); без вердикта чекера модуль = Draft (deploy и Anki закрыты). ## 3. Применимый результат (прототип)

**Осязаемый результат**, которым кончается модуль: что зафиксирует `/deploy`. Форма зависит от предмета — артефакт ≠ только «изделие»:
- **Изделие/код** (электроника, 3D-печать, программирование) — собранный прототип, напечатанная деталь, работающий скрипт.
- **Применённое действие** (общение, спорт) — проведённый реальный разговор / выполненное действие + запись-свидетельство.
- **Письменный результат** (философия, продуктивность) — заполненный разбор / решение, пересобранное через рамку / настроенная система / личное правило с триггером.

**Теория без применения не считается.** **Без §3 модуль не апрувится** (см. §«Проверка»).

## Мосты (связи с другими модулями) — REQUIRED

Breadth без мостов = изолированные островки. Каждый модуль связывает с пройденным.

- **Опирается на (внутренний мост):** какие прошлые модули этого проекта задействует — и **понимание**, и **практику** (какой реальный артефакт прошлого модуля переиспользует). `moduleId` прошлых модулей.
- **Внешний мост (опц.):** связь с **другим учебным проектом** (другая папка-курс) — где идея этого модуля применяется в другом предмете. Свободный текст (`<проект> — <как применяю вместе>`); не enforced, но желателен — учёба не должна лежать в силосах.
- **Задел на будущее:** что этот модуль даёт следующим (на чём его потом смогут построить).

**Гейт связности:** если в проекте уже есть пройденный (`Done`) модуль — нужен ≥1 мост «опирается на». Нет моста → модуль-островок, вернуть в `/plan` (искать связь или поставить раньше пред-модуль). Исключение — самый первый модуль проекта (мостить не к чему).

## Проверка перед практикой (Mental tests — REQUIRED для Approved)

Гейт: без заполненного блока `/plan` и `/go` НЕ пропустят модуль в `Approved`. Пять проверок:

Ответы — **с обоснованием**, не голым «да» (голое «да» = rubber-stamp, гейт не сработал).

| # | Проверка | Ответ |
|---|----------|-------|
| 1 | **Реальная практика?** Есть применимый результат (§3), не «прочитал и кивнул»? | … |
| 2 | **Готовность наблюдаема?** §9 проверяем извне, не «понял»? | … |
| 3 | **Есть чем делать?** §4 на руках сейчас? Иначе → Blocked | … |
| 4 | **Теория just-in-time?** §2 — минимум до сборки, не учебник? Раздув → backlog | … |
| 5 | **Применю потом?** Через неделю повторю/применю? (это проверит `/exam`) | … |

Любой «нет» → пересмотреть модуль или развернуть в `Blocked` / `docs/backlog.md`, не гнать в практику.

**Плюс гейт связности:** §«Мосты» заполнен (≥1 мост «опирается на» для не-первого модуля). Островок без связей не апрувится.
