# Мировая история — автономный учебный курс

Самодостаточная папка курса: распакуй, открой в агенте (Claude Code или ZCode) — и учись. Ничего настраивать не нужно.

## Быстрый старт

1. Открой папку `world-history` как рабочую в Claude Code или ZCode.
2. Скажи: **«что сегодня»** (или `/do`) — агент сам подхватит курс: покажет карту предмета, текущий модуль и предложит следующий шаг.
3. Дальше просто говори с агентом по-человечески: «объясни», «хочу разобраться с X», «проверь меня» — он ведёт по методологии, записанной в `CLAUDE.md`.

## Что внутри

- `AGENTS.md` / `CLAUDE.md` — протокол курса для агента: методология PING, цикл модуля `in → plan → go → deploy`, контроль фактов, роли tutor/examiner/checker.
- `docs/roadmap.md`, `docs/epochs-overview.md` — дорожная карта тура и материалы по эпохам.
- `docs/modules/` — модули (единица работы); `docs/plans/` — реестр; `docs/journal.md` — журнал обучения.
- `artifacts/` — сюда агент складывает результаты твоих модулей: шпаргалки эпох (`artifacts/epochs/`), ленту тура (`timeline.md`), Anki-колоды (`artifacts/anki/`), аудио-версии (`artifacts/audio/`). Папки стартуют пустыми — первый артефакт появится, когда закроешь первый модуль.
- `.claude/` и `.zcode/` — скиллы и субагенты для агента. Трогать не нужно.

Курс стартует с нуля: прогресс — 0 из 18 эпох, первая сессия — эпоха 1 («Неолит и первые цивилизации»). Скажи агенту «что сегодня» — он предложит начать.

## Зависимости

Обязательных нет — нужен только сам агент.

- **Опционально git:** агент коммитит шаги; если git не установлен/не настроен — просто попроси работать без коммитов.
- **Опционально Python 3:** генерация аудио (`scripts/make-audio.py`).
- **Опционально Anki + AnkiConnect:** скилл `/anki`; без Anki агент его просто пропускает.

Никаких синхронизаций, удалённых репозиториев, MCP-серверов и токенов в папке нет.

## Главная команда

`/do` — единственная команда, которую нужно помнить: без аргумента «что сегодня», с темой — вплести в план. Весь цикл (`объяснить → спроектировать модуль → практика → зафиксировать результат`) `/do` ведёт сам. `/deploy` в этом курсе означает «зафиксировать результат модуля» (артефакт + журнал), а не развёртывание приложения.
